## Dependency updates

Dependabot is configured in [`.github/dependabot.yml`](.github/dependabot.yml). It checks **npm** (repo root) and **GitHub Actions** weekly (Mondays) and opens PRs here when versions can move.

- Patch and minor **npm** bumps are grouped into one PR; major npm bumps stay individual so they can be reviewed (and may need app changes).
- **GitHub Actions** bumps are grouped into one PR.
- PRs are labeled `dependencies`. If this repo also has `major` / `minor` / `patch` labels, Dependabot may add those too — merging a labeled PR can mint a SemVer tag via the release workflow.

Version updates only run after Dependabot version updates are enabled on the GitHub repo (Settings → Code security → Dependabot). After that, confirmation is a Dependabot check/run on the Insights → Dependency graph → Dependabot tab, or a clear “no updates” state — not just the presence of this file.
